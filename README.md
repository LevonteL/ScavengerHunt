# Scavenger Hunt

Scavenger Hunt is an iOS app that allows users to complete a list of scavenger hunt tasks by attaching photos. The app was built using Swift and UIKit in Xcode.

## Features

- Displays a list of scavenger hunt tasks
- Users can tap a task to view its details
- Users can attach a photo to complete a task
- Completed tasks are visually marked as completed
- Selected photos are displayed on the task detail screen
- Uses PHPicker to select photos from the photo library
- Uses MapKit to display photo location information

## Technologies Used

- Swift
- UIKit
- Xcode
- PHPicker / PhotosUI
- MapKit
- Storyboards

## How It Works

1. Launch the app to view the scavenger hunt task list.
2. Tap a task to open its detail screen.
3. Tap **Attach Photo**.
4. Select a photo from the photo library.
5. The selected photo is displayed and the task is marked as completed.
6. Return to the task list to see the completed task indicator.

## Scavenger Hunt Tasks

The app includes tasks such as:

- Take a photo of something red
- Find something outdoors
- Take a photo of something interesting
